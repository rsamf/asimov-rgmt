How it works

Try out my whole body control policy! The directional inputs that you use, control a locomotion controller implemented via Motion Matching. Inspired by video games, I use Motion Matching to select the most optimal clip out of a corpus of retargeted AMASS locomotion clips, at each simulation step, given directional and rotational inputs (W/A/S/D + Q/E). Such clips include the humanoid walking forward, backwards, strafing, and turning.

These fetched clips from motion matching are essentially, used as the reference motion inputs into the whole body control (WBC) policy. The WBC policy takes the reference motions and command velocities and outputs the low-level actions delivering them into the PD controller, so that it can move the Asimov based on the input motion, safely without falling.
